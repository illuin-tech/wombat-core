# LLM Prometheus Module

| Property           | Value                                                          |
|--------------------|----------------------------------------------------------------|
| **Technical Name** | `tech.illuin.wombat-module.llm-prometheus`                     |
| **Family**         | `LLM`                                                          |
| **Java Class**     | `tech.illuin.wombat.module.llm_prometheus.LLMPrometheusModule` |
| **Components**     | `source` (`LLMPrometheusSource`)                               |

## Description

The **LLM Prometheus Module** polls Prometheus endpoints using PromQL expressions to capture live token throughput and request metrics generated by LLM serving engines and AI gateways (such as vLLM, LiteLLM proxy, Ollama, TGI, or custom corporate inference proxies).

Use this module when:
- You run self-hosted open-source models on inference servers exposing Prometheus metrics.
- You operate an LLM API gateway that tracks token usage per model or consumer.
- You want real-time telemetry ingestion into Wombat's metric store with support for corporate proxies and authenticated endpoints.

## Configuration Specification

The module registers the asset type `tech.illuin.wombat-module.llm-prometheus` (`LLMPrometheusAsset`) with a profile configuration (`LLMPrometheusProfile`).

For cross-cutting data formats such as `Period`, `Country`, and `LLMProvider`, refer to the [Generic Type Glossary](../type-glossary.md).

```yaml
id: "vllm-mistral-7b" # required - Unique identifier for the asset.
environment-id: "production" # required - Identifier of the environment (e.g. `production`, `staging`).
name: "Self-Hosted Mistral 7B Service" # required - Human-readable asset name.
prometheus-url: "http://prometheus.internal:9090" # required - Base HTTP/HTTPS URL of the Prometheus server.
proxy-url: "http://proxy.corp.internal:8080" # optional (default: null) - HTTP/HTTPS corporate proxy URL if routing through an outbound proxy.
username: "wombat-agent" # optional (default: null) - Basic authentication username.
password-key: "secrets.prometheus.password" # required if username is set - Secret resolver key for the Basic auth password.
period: "5m" # optional (default: monitor default) - Polling interval for metric sampling (e.g. `1m`, `5m`, `15m`).
profile: # required - LLM profile and PromQL query configuration.
  provider: "mistralai" # required - Foundation model provider (`anthropic`, `mistralai`, `openai`, `huggingface_hub`, `cohere`, `google_genai`).
  model: "mistralai/Mistral-7B-Instruct-v0.2" # required - Standardized model identifier.
  location: "FRA" # required - ISO 3166-1 alpha-3 (or alpha-2) country code where inference occurs.
  dynamic-profile: # required - Dynamic PromQL metric query configuration.
    query: "sum(increase(vllm:num_tokens_total{model_name=\"mistralai/Mistral-7B-Instruct-v0.2\",type=\"generation\"}[5m]))" # required - PromQL query returning the output token volume over the sampling window.
```

## Basic Setup

A minimal configuration scraping output token generation from a local vLLM instance every 5 minutes.

```yaml
id: "vllm-mistral-7b"
environment-id: "production"
name: "Self-Hosted Mistral 7B Service"
prometheus-url: "http://prometheus.internal:9090"
period: "5m"
profile:
  provider: "mistralai"
  model: "mistralai/Mistral-7B-Instruct-v0.2"
  location: "FRA"
  dynamic-profile:
    query: "sum(increase(vllm:num_tokens_total{model_name=\"mistralai/Mistral-7B-Instruct-v0.2\",type=\"generation\"}[5m]))"
```

## Advanced Setup

### Authenticated Enterprise AI Gateway Behind Proxy

In an enterprise environment, multiple foundation models are served via an internal AI gateway proxy. Metric queries must route through an outbound corporate HTTP proxy and authenticate against a secured central Prometheus cluster with credentials managed via Wombat's secret provider.

The example below demonstrates:
1. **Llama-3-70B Deployment** hosted on dedicated GPU clusters in France.
2. **Mistral-Large Deployment** monitored with custom PromQL label filtering and authenticated credentials.

```yaml
---
# Asset 1: Meta Llama-3-70B Service on Enterprise Gateway
id: "gateway-llama3-70b"
environment-id: "production"
name: "Enterprise Gateway - Llama 3 70B"
prometheus-url: "https://prometheus-mon.corp.internal:9090"
proxy-url: "http://proxy.corp.internal:8080"
username: "wombat-agent"
password-key: "secrets.prometheus.gateway-password"
period: "1m"
profile:
  provider: "huggingface_hub"
  model: "meta-llama/Meta-Llama-3-70B-Instruct"
  location: "FRA"
  dynamic-profile:
    query: "sum(increase(ai_gateway_tokens_total{model=\"llama-3-70b\",direction=\"output\"}[1m]))"

---

# Asset 2: Mistral Large Endpoint
id: "gateway-mistral-large"
environment-id: "production"
name: "Enterprise Gateway - Mistral Large"
prometheus-url: "https://prometheus-mon.corp.internal:9090"
proxy-url: "http://proxy.corp.internal:8080"
username: "wombat-agent"
password-key: "secrets.prometheus.gateway-password"
period: "1m"
profile:
  provider: "mistralai"
  model: "mistral-large-2407"
  location: "FRA"
  dynamic-profile:
    query: "sum(increase(ai_gateway_tokens_total{model=\"mistral-large\",direction=\"output\"}[1m]))"
```
